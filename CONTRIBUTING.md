# Как помочь проекту

Спасибо за помощь! Пожалуйста, сначала проверьте существующие Issues и не публикуйте личные данные из DeepSeek.

## Сообщить об ошибке

Откройте **Issues → Bug report**, укажите браузер и его версию, версию расширения, страницу (если она публична), шаги воспроизведения, ожидаемый и фактический результат. Особенно полезны ошибки установки, отправки, боковой панели и выделения в iframe. Удалите токены, cookies и чужие переписки из скриншотов.

## Изменить код

1. Создайте fork и рабочую ветку.
2. Старайтесь сохранять общую логику выделения и существующие политики безопасности; не добавляйте обходы CSP, удалённые скрипты и неофициальные API.
3. Запустите TypeScript-проверку и тесты (`npm run typecheck`, `npm test`, `npm run build:all`).
4. Для изменений в браузерной интеграции проверьте установку и ручную отправку **в конкретном браузере**, а не только мок-тесты.
5. Откройте Pull Request с описанием изменения, тестов и затронутых браузеров.

## Сборки

Не редактируйте файлы внутри ZIP как первоисточник. Исходные файлы — `src/` и `chromium/`; `scripts/build-all.mjs` генерирует `releases/<browser>/`. Готовые файлы в `downloads/` обновляются только при подготовке нового релиза вместе с `SHA256SUMS.txt`.

## Стиль

Простая архитектура, минимальные разрешения, ясные сообщения об ошибках и никаких ложных подтверждений отправки. Для сложной браузерной совместимости приложите воспроизводимый тест.
