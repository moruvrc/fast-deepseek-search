# moru's deepseek

**Выделяйте текст на странице и отправляйте его в DeepSeek, не копируя вручную.**

Кроссбраузерное расширение с компактной панелью выделения, предварительным редактированием промпта и тёмным интерфейсом. Работает с официальным веб-сайтом [DeepSeek](https://chat.deepseek.com/) **без API-ключей и собственного сервера**.

**Версия:** `2.0.0` · **Статус:** Release Candidate (`v2.0.0-rc.1`) · **Лицензия:** [MIT](LICENSE)

> [!IMPORTANT]
> Это **неофициальный проект**, не связанный с DeepSeek. Сборки прошли автоматические и локальные проверки, но полноценная отправка сообщений в авторизованном DeepSeek во всех девяти браузерах **ещё не подтверждена**. Пока это предварительный релиз для тестирования, а не проверенный production-релиз.

## Возможности

- **Быстрая отправка:** выделите текст и нажмите кнопку отправки.
- **Редактирование запроса:** добавьте собственную инструкцию, сохранив выделенный текст без изменений.
- **Отдельный диалог:** новая отправка выделения предназначена для создания нового чата; существующий чат можно продолжать вручную.
- **Компактный интерфейс:** тёмная тема, минималистичные кнопки и адаптация под узкую панель.
- **Работа на обычных сайтах:** обработка выделения, в том числе в доступных iframe, текстовых полях и открытом Shadow DOM.
- **Без DeepSeek API:** авторизация и ответы выполняются официальным веб-приложением.
- **Безопасная очередь:** при неопределённом результате отправка не повторяется автоматически, чтобы уменьшить риск дубликатов.

Совместимость с конкретными версиями браузеров и текущей разметкой DeepSeek может меняться.

## Установщики для Windows и Linux

Для удобства подготовлены **27 скриптов**: по одному для каждого из девяти браузеров на каждой из трёх платформ.

| Платформа | Скачать | Формат |
|---|---|---|
| Все платформы | [Полный комплект установщиков](downloads/morus-deepseek-installers-all-platforms-v2.0.0.zip) | `.ps1`, `.cmd`, `.sh` |
| Windows 11 | [PowerShell](downloads/morus-deepseek-installers-win11-powershell-v2.0.0.zip) | `.ps1` |
| Windows 10 | [Command Prompt](downloads/morus-deepseek-installers-win10-cmd-v2.0.0.zip) | `.cmd` |
| Linux | [Terminal / Bash](downloads/morus-deepseek-installers-linux-terminal-v2.0.0.zip) | `.sh` |

> [!WARNING]
> **Скрипты устанавливают не браузер, а подготавливают к установке расширение moru's deepseek.** Нужный браузер уже должен быть установлен на компьютере. Скрипты проверяют целостность ZIP (SHA-256), распаковывают расширение в пользовательскую папку, ищут браузер и открывают страницу управления дополнениями. **Окончательная установка чаще всего требует ручного подтверждения** в браузере. Успешный запуск скрипта сам по себе не означает, что расширение установлено.

### Быстрый запуск

Распакуйте скачанный комплект **целиком**. Откройте терминал в распакованной папке. Не запускайте скрипты прямо из ZIP.

**Windows 11, PowerShell** (пример для Opera GX):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\win11-powershell\install-opera-gx.ps1
```

**Windows 10, CMD** (пример для Firefox):

```bat
win10-cmd\install-firefox.cmd
```

**Linux, Bash** (пример для Chrome):

```bash
bash linux-terminal/install-chrome.sh
```

В имени скрипта вместо `opera-gx`, `firefox` или `chrome` укажите нужный браузер:

`firefox`, `chrome`, `edge`, `brave`, `vivaldi`, `opera`, `opera-gx`, `yandex`, `chromium`.

Например, для Яндекс Браузера на Windows 11: `win11-powershell/install-yandex.ps1`.

**Что делать после запуска:**

1. Дождитесь проверки архива и распаковки.
2. Если браузер найден, откроется страница расширений; если нет, скрипт сообщит об этом.
3. Для Chromium-браузеров включите **Режим разработчика / Developer mode**, нажмите **Загрузить распакованное / Load unpacked** и укажите папку, которую вывел скрипт.
4. Для Firefox откройте `about:debugging#/runtime/this-firefox`, выберите **Загрузить временное дополнение** и укажите файл `manifest.json` внутри подготовленной папки.
5. Убедитесь, что `moru's deepseek` появился в списке расширений. При необходимости предоставьте доступ к сайтам и авторизуйтесь на официальном DeepSeek.

На **Windows** файлы подготавливаются в `%LOCALAPPDATA%\morus-deepseek\extensions\`, а на **Linux** в `${XDG_DATA_HOME:-$HOME/.local/share}/morus-deepseek/extensions/`.

Некоторые версии Opera GX и Яндекс Браузера недоступны на отдельных дистрибутивах Linux. В таком случае соответствующий скрипт не сможет открыть отсутствующий браузер.

### Дополнительные параметры

- **PowerShell:** `-NoLaunch` для одной лишь распаковки; `-DevSession` для попытки запуска поддерживаемой тестовой сессии.
- **CMD:** `-NoLaunch` и `-DevSession` передаются PowerShell-компоненту.
- **Linux:** `--no-launch` и `--dev-session`.

`-DevSession` не означает постоянной установки. Для временной установки Firefox в этом режиме необходим заранее установленный `web-ext`; для Chromium применяется отдельный тестовый профиль. Подробные условия и коды завершения описаны в `README.md` внутри каждого пакета установщиков.

**Ограничения:** постоянная установка неподписанного расширения в обычный Firefox требует подписи Mozilla; Chrome не поддерживает прежний способ загрузки расширений через `--load-extension` в актуальных официальных сборках; Яндекс Браузер может ограничивать неподписанные дополнения. Скрипты не отключают защиту, не изменяют корпоративные политики и не обходят требования браузеров.

## Ручная установка без скриптов

Если предпочитаете ручную установку, распакуйте ZIP нужного браузера:

- **Firefox:** откройте `about:debugging#/runtime/this-firefox` → **Загрузить временное дополнение** → выберите `manifest.json`. Дополнение исчезнет после перезапуска Firefox.
- **Chrome / Edge / Brave / Vivaldi / Chromium:** откройте управление расширениями → включите **Режим разработчика** → **Загрузить распакованное** → выберите папку с `manifest.json`.
- **Opera / Opera GX:** откройте `opera://extensions` → включите режим разработчика и загрузите распакованную папку, если это поддерживается установленной версией.
- **Яндекс Браузер:** установка из ZIP не гарантируется; для постоянного распространения может потребоваться подписанный CRX3 или публикация в магазине дополнений.

Дополнительная инструкция: [docs/INSTALLATION.md](docs/INSTALLATION.md).

## Как это работает

**Firefox:** использует Firefox Sidebar API для работы с официальной страницей DeepSeek в боковой панели и внедряет адаптированный интерфейс через content script.

**Chromium-браузеры:** используют собственный UI расширения и отдельную связанную вкладку официального DeepSeek. Наличие Side Panel API зависит от браузера и его версии. Не все функции официального DeepSeek доступны непосредственно в кастомной панели: некоторые действия выполняются в связанной вкладке.

В новых диалогах возможны изменения из-за обновлений DOM DeepSeek. На служебных страницах браузеров (`about:`, `chrome://` и аналогичных), защищённых страницах и в некоторых PDF расширения не могут показывать кнопки выделения.

Расширению требуется доступ к содержимому посещаемых страниц для обнаружения выделения. Информация о разрешениях и обработке текста находится в [PRIVACY.md](PRIVACY.md). Официальный DeepSeek самостоятельно обрабатывает отправленные ему сообщения согласно собственным условиям.

## Проверка качества

**Проверено локально:**

- Типизация TypeScript и **13 автоматических JS-тестов** расширения.
- **6 браузерных тестов с имитацией редактора** DeepSeek.
- Локальные сценарии выделения в формах, iframe и открытом Shadow DOM.
- Работа узкого Chromium-интерфейса и целостность ZIP.
- **87 автоматических проверок установщиков**, включая SHA-256, распаковку и повторный запуск; Linux-сценарии проверялись на тестовой среде.

**Пока не проверено:** реальная отправка через авторизованный DeepSeek во всех браузерах, сквозные тесты установки на Windows 10/11 и запуск на девяти реальных браузерах, публикация и подпись в магазинах расширений.

Таким образом, **v2.0.0 остаётся Release Candidate**, а не подтверждённым стабильным релизом. Отчёты: [проверки расширения](RELEASE-TEST-REPORT.txt), [примечания к выпуску](RELEASE.md) и `INSTALLERS-TEST-REPORT.md` внутри пакетов установщиков.

## Сборка из исходников

Требуются **Node.js 18+**, **TypeScript CLI (`tsc`)** и **Python 3** для инструментов упаковки.

```bash
npm run typecheck
npm test
npm run build:all
python3 scripts/verify_release.py
```

`npm test` подготавливает Firefox-сборку в `dist/`, а `build:all` создаёт версии в `releases/<browser>/`. Готовые ZIP расположены в `downloads/`. **Изменение исходников само по себе не обновляет ZIP:** пересоберите архивы и обновите контрольные суммы перед следующим релизом.
