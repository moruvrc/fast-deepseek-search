# moru's deepseek

**Независимое расширение для отправки выделенного текста в официальный DeepSeek.**

**Версия:** `2.0.0` · **Статус:** Release Candidate (RC), **не прошёл полную проверку для production** · **Лицензия кода:** MIT.

> Это неофициальный проект, не связанный с DeepSeek. Для работы используется официальный сайт [chat.deepseek.com](https://chat.deepseek.com/). Никакие API-ключи DeepSeek не нужны. Официальный сайт и его правила обработки данных остаются отдельным сервисом.

## Что умеет

- Две компактные кнопки возле выделенного текста: отправить напрямую или дополнить собственной инструкцией.
- Вторая кнопка показывает всплывающий редактор с неизменяемым выделением.
- Новое выделение создаёт новый чат, вручную можно продолжить текущий разговор (при доступности интеграции).
- Тёмный интерфейс, поддержка обычных сайтов, встроенных рамок и доступного открытого Shadow DOM.
- Работа через официальный веб-интерфейс DeepSeek, а не имитация ответов.
- Ожидающие запросы хранятся локально; после неопределённого результата расширение не отправляет их повторно автоматически.

Стабильность этих функций на **реальном DeepSeek во всех браузерах не подтверждена**: интеграция зависит от структуры чужого сайта и поддержки браузерных API.

## Быстрая установка

**Firefox:** распакуй соответствующий ZIP → `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → выбери `manifest.json`.

**Chrome / Edge / Brave / Vivaldi / Chromium:** распакуй свой ZIP → страница управления расширениями → режим разработчика → **Load unpacked / Загрузить распакованное** → выбери папку с `manifest.json`.

**Opera / Opera GX:** `opera://extensions` → режим разработчика → загрузка распакованного расширения, если функция доступна.

**Яндекс Браузер:** способ установки зависит от версии и её ограничений, обычный ZIP не гарантирует установку.

Подробности: [docs/INSTALLATION.md](docs/INSTALLATION.md) и [docs/TESTING.md](docs/TESTING.md).

## Как это работает

**Firefox** может открывать официальный `chat.deepseek.com` в боковой панели; расширение адаптирует интерфейс страницы. **Chromium-браузеры** используют собственную панель расширения и связанную вкладку официального DeepSeek. Chromium Side Panel не означает прямого встраивания чужого сайта. Режимы DeepThink, веб-поиск и отправка файлов в Chromium доступны через официальную вкладку, если их предоставляет сам DeepSeek.

Доступ `host_permissions: ["<all_urls>"]` нужен для появления кнопок при выделении текста на разных страницах. Расширение не может внедряться в служебные вкладки браузера, некоторые PDF и иные защищённые страницы. На стороне DeepSeek применяется его собственная политика конфиденциальности.

## Разработка из исходников

В корне лежит редактируемый исходный проект (`src/`, `chromium/`, `scripts/`, `tests/`), а не только готовые архивы. Требуются **Node.js 18+**, **TypeScript CLI (`tsc`)** и для упаковки **Python 3**. Если `tsc` отсутствует, сначала установи TypeScript в окружение разработки.

```bash
npm run typecheck
npm test
npm run build:all
python3 scripts/verify_release.py
```

`npm test` собирает `dist/` для Firefox и архивы в `artifacts/`; `build:all` создаёт **`releases/<browser>/`** (сборки без упаковки). Готовые ZIP v2.0.0 остаются в `downloads/`. Изменения исходников **не меняют** ZIP автоматически; после нового билда их необходимо заново упаковать и обновить контрольные суммы.

## Подтверждённые проверки и ограничения

- Выполнены: TypeScript, **13 JS-тестов**, **6 офлайн browser-mock сценариев редактора**, проверки выделения/iframe/Shadow DOM, локальный UI Chromium 320 px и целостность ZIP.
- Не выполнены: авторизация и настоящая отправка в DeepSeek при установленном расширении, полноценные E2E-тесты в 9 браузерах, проверка подписей и публикации в магазинах.
- Установку расширения в тестовом Chromium заблокировала политика окружения. Поэтому **v2.0.0 не следует выдавать за проверенный production-релиз**.
