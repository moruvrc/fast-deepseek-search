# Проверки и критерии публикации

Ниже разделены **фактически пройденные** проверки v2.0.0 и **обязательные ещё не выполненные** проверки. Проект нельзя объявить production-ready только по прохождению линтера.

## Автоматически проверено ранее

- TypeScript typecheck.
- 9 тестов логики Firefox + 4 Chromium.
- 6 офлайн сценариев ввода в редактор на локальной имитации DeepSeek.
- Выделение текста на обычной странице, в доступном iframe, открытом Shadow DOM и формах.
- Интерфейс панели Chromium на тестовой странице, ширина 320 px.
- JSON манифестов, ссылки на статические файлы, JS-синтаксис и целостность ZIP.

Указанные факты основаны на [отчёте предыдущей сборки](../RELEASE-TEST-REPORT.txt). Тесты с реальной серверной сессией в 9 браузерах не проводились.

## Обязательный ручной E2E-чек-лист перед production

- [ ] Установка/запуск расширения в актуальном Firefox.
- [ ] Установка/запуск расширения в актуальном Chrome и Chromium.
- [ ] Отдельная проверка Edge, Brave и Vivaldi (при их заявленной поддержке).
- [ ] Отдельная проверка Opera и Opera GX (наличие запасной вкладки).
- [ ] Реальная установка в Яндекс Браузер с допустимым пакетом/подписью.
- [ ] Появление двух кнопок при выделении короткого и длинного текста на нескольких обычных сайтах.
- [ ] Редактируемый промпт + неизменяемое выделение в превью.
- [ ] Отправка только выбранного текста; новый чат на каждое новое выделение.
- [ ] Реальный ответ DeepSeek из авторизованного аккаунта.
- [ ] Ручное продолжение существующего чата.
- [ ] Отсутствие дубликатов при быстрых кликах, сбоях сети и обновлении страницы.
- [ ] DeepThink, поиск и загрузка файлов в том варианте интерфейса, где их предоставляет официальный DeepSeek.
- [ ] Корректное поведение при закрытом сайдбаре, отсутствии доступа к сайту и после перезапуска.
- [ ] Оценка безопасности расширенных разрешений и приватности сохранённых сообщений.
- [ ] Проверка упаковки/подписи, условий магазинов и версии публикуемых артефактов.

## Локальный контроль архивов

```bash
python3 scripts/verify_release.py
```

Скрипт проверяет наличие ожидаемых ZIP, манифесты, файлы внутри архивов и SHA-256 из `SHA256SUMS.txt`. Он **не доказывает**, что расширение работает с реальным DeepSeek.
