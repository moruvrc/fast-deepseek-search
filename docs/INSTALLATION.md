# Установка moru's deepseek v2.0.0

**Текущий статус: RC, требуется тестирование в целевом браузере.** Каждый ZIP уже содержит `manifest.json` в корне архива. Распакуйте ZIP перед загрузкой через режим разработчика.

## Firefox

1. Распакуйте `downloads/morus-deepseek-firefox-2.0.0.zip`.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение» и выберите `manifest.json`.
4. Если потребуется, разрешите доступ к веб-страницам в `about:addons`.
5. Откройте официальный DeepSeek в панели, выполните вход и попробуйте выделение текста на обычной странице.

Такое дополнение **временное**. Для постоянной установки необходима подписанная сборка через систему Firefox Add-ons, просто ZIP недостаточно.

## Chrome / Chromium / Edge / Brave / Vivaldi

1. Распакуйте ZIP именно для вашего браузера.
2. Откройте страницу управления расширениями: `chrome://extensions`, `edge://extensions`, `brave://extensions`, `vivaldi://extensions` (адрес зависит от браузера).
3. Включите **Режим разработчика** и выберите **Загрузить распакованное / Load unpacked**.
4. Выберите каталог, содержащий `manifest.json`.
5. Дайте доступ к страницам и нажмите значок расширения.

В Chromium-разновидностях официальный DeepSeek открывается в **связанной вкладке**, даже если собственный интерфейс расширения доступен в Side Panel. Некоторые браузеры могут ограничивать API Side Panel.

## Opera / Opera GX

1. Распакуйте соответствующую сборку.
2. Откройте `opera://extensions` и включите режим разработчика.
3. Если ваша версия позволяет загрузить распакованное расширение, выберите папку с `manifest.json`.

Панель управления расширением здесь открывается во **вкладке**, как запасной режим; идентичное Firefox Sidebar поведение не заявляется.

## Яндекс Браузер

Распакуйте ZIP и проверьте доступный вашей версии способ установки сторонних расширений. **Возможна необходимость подписанного CRX3.** Наличие ZIP в релизе не доказывает, что браузер позволит его установить. Если доступна только установка из магазина, потребуется публикация и проверка магазином.

## Быстрая самопроверка

1. Выделите текст на обычном HTTPS-сайте: должны появиться две кнопки.
2. Нажмите отправку: проверьте, что текст появился в **новом** чате DeepSeek.
3. Отправьте запрос с собственной инструкцией.
4. Вручную продолжите разговор, убедитесь в отсутствии дублей.
5. Проверьте поведение без авторизации, при пропавшей сети и после обновления вкладки.

Расширения не могут изменять служебные страницы вроде `about:debugging`/`chrome://extensions`; это нормальное ограничение платформы, а не дефект выделения.
