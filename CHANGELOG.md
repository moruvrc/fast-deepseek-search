# Changelog

Изменения документируются в обратном хронологическом порядке. Ниже отражены особенности опубликованного набора файлов, а не обещание отсутствия ошибок.

## [2.0.0] — 2026-10-16 (Release Candidate)

### Добавлено
- Девять отдельных сборок для Firefox, Chrome, Edge, Brave, Vivaldi, Opera, Opera GX, Яндекс Браузера и Chromium.
- Chromium-реализация панели с сопряжённой вкладкой официального DeepSeek.
- Разделение сценариев для браузеров с Side Panel и без него.
- Единый исходный проект и скрипты сборки всех вариантов.

### Сохранено из ветки Firefox 1.x
- Компактные действия над выделением, редактирование промпта и очередь отправки.
- Обработка нескольких типов редакторов и подтверждения отправки.
- Поддержка выделения на обычных страницах, в доступных iframe и открытом Shadow DOM.

### Известные ограничения
- Непроверенные реальные E2E-сценарии DeepSeek и установки в каждом целевом браузере.
- Изменения DOM DeepSeek могут нарушить интеграцию.
- Часть браузеров не предоставляет стандартную боковую панель или допускает установку только подписанных пакетов.

История отдельных исправлений Firefox 1.x находится в предыдущих сборках; этот журнал не заменяет журнал коммитов.
